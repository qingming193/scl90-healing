# 心之迷宫 · SCL-90 心理健康深度自测产品（纪念碑谷风格重构版）

## 🎯 项目概况与重构价值
本项目是针对小红书虚拟资料与心理自测变现项目开发的 **高转化移动端自测工具**。
设计全面贯彻 **【纪念碑谷几何超现实主义治愈风】（Monument Valley Healing Aesthetic）**，旨在彻底消除传统医学量表的冰冷感与用户的病耻感，大幅降低中途跳出率，构建顺畅的“测试 ➔ 分级报告 ➔ 虚拟资料变现”闭环。

---

## 🎨 视觉与体验核心升级点

1. **移动端第一（Mobile-First）极致自适应**：
   - 界面锁定手机竖屏视口（最大宽度 480px），消除 PC 端大网页在手机上的缩放卡顿。
   - 采用温润燕麦奶油底色（`#FAF8F5`）、砂岩柔灰与低饱和浅粉、薄荷绿、淡暮蓝搭配。
2. **纪念碑谷 3D 等距几何插画**：
   - 页面顶部内置纯 SVG 矢量绘制的纪念碑谷微建筑：粉色拱门、悬浮阶梯、微光通道与微型白帽旅人（情绪共鸣锚点）。
3. **沉浸式单题卡片 + 自动跳题体验（核心降流失机制）**：
   - 每次屏幕只聚焦 1 道题目，彻底打消面对 90 道题的压迫感。
   - 5 个大药丸选项按钮，触控点击后带弹性微动效，**延迟 220ms 自动平滑滑入下一题**，无需频繁点击“下一题”。
   - 顶部搭配“90 级台阶”进度条与动态切换的情绪陪伴抚慰语。
4. **对标爆款同款评估结果页**：
   - 顶部醒目大字号总分显示（如 `387` 分），搭配温和的马卡龙药丸标签（`重度 · 困扰突出`）。
   - ECharts 定制多维几何切面雷达图，直观展现 10 大因子的情绪短板。
   - 10 个细分维度（躯体化、强迫、人际敏感、抑郁、焦虑等）配有独立状态呼吸灯微卡片。
5. **商业变现卡点闭环（Lock Zone）**：
   - 基础评级和雷达图免费查看，建立信任感。
   - 下方《深度心理归因与 7 天自愈处方指南》采用柔和高斯模糊毛玻璃锁区，点击引导关注小红书、加入陪伴群或私信领取虚拟资料包。
6. **一键生成 9:16 小红书打卡海报**：
   - 内置纯前端 `html2canvas` 高保真长图生成，用户可一键生成精美海报长按保存，分享至小红书返图打卡。
